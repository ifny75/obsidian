Создать приватный аккаунт

Регистрация открыта для всех. Выберите имя — после первого входа приложение будет подключаться автоматически.

Ключ базы хранится только в защищённом хранилище Windows.

Как это защищено

  • Шифрование на устройстве. Сообщения шифруются по MLS (RFC 9420) до отправки. Ключи не покидают компьютер: их нет ни у нас, ни у того, кто держит сервер.
  • Состав беседы задают устройства. Подсунуть лишнего участника сервер не может — проверка идёт перед каждой отправкой, и при несходстве текст просто не уходит.
  • Хранилище запечатано. Каждая запись зашифрована отдельно, ключ выведен из пароля устройства и на диск не попадает.

Почему серверу не нужно доверять

Ему достаётся запечатанный конверт, адрес получателя и время — без этого письмо не доставить. Открыть конверт нечем: ключей у сервера нет, поэтому прочитать переписку он не может ни по просьбе, ни по ошибке. Проверяется это не обещанием: исходники открыты, и сервер можно поднять свой.

            Сервер

            Открыто потому, что сервер признал ключ этой личности своим владельцем.

            Панель владельца сервера Открыта потому, что сервер признал ключ этой личности своим владельцем. Здесь только счётчики и доступ ко входу: переписку владелец прочитать не может — она зашифрована на устройствах, — и кто кому пишет, сервер не хранит.
            Доступ к серверу Код чата OBS-…, адрес устройства или ключ личности. Заблокированный не сможет войти; уже доставленное у него останется.

            Аккаунты Всё, что сервер о них знает: код чата, сколько устройств и когда заходили. Юзернеймов здесь нет и быть не может — каталог хранит только отпечатки имён.
