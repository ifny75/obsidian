Obsidian

Приватный мессенджер для закрытого круга. Вход только по приглашению, минимум публичных данных и простой интерфейс без лишнего шума.

Прототип интерфейса. Криптография и серверная часть в этой версии не реализованы.

Приглашение

Для доступа нужен код участника закрытого круга.

Тестовые коды:
обычный — OBSIDIAN-0420
owner — OWNER-0420
dev-пропуск — DEV-0420
